# MD Digital — sajt

Statičan sajt spreman za GitHub Pages.

## Objava
1. Otpremi SADRŽAJ ovog foldera u koren repozitorijuma.
2. Settings → Pages → Source: *Deploy from a branch* → `main` / `(root)`.
3. Za domen mddigitalweb.com: dodaj domen u Settings → Pages (napraviće CNAME fajl) i podesi DNS kod registrara.

## Stranice
- `index.html` — početna
- `uslovi-koriscenja.html`
- `politika-privatnosti.html`
